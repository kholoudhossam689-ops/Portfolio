Binzoi — Splash Screen
The Design Challenge

Make complexity feel natural.

A dark-fantasy RPG interface needs to carry the atmosphere and visual weight of its world — but it still needs to work as a UI. Inventory management, character selection, and navigation all have to be clear and instinctive.

The challenge was designing an interface that respects the dark, cinematic tone of the Binzoi world while making every interaction — selecting a character, equipping an item, switching screens — feel immediate and readable.

Visual richness had to serve usability, not compete with it.

Visual Direction

Atmosphere with intention.

Every visual decision in the Binzoi interface was made to reinforce the dark-fantasy world without sacrificing clarity. The goal was a premium interface that feels handcrafted for this specific game world.

01

Dark Fantasy Atmosphere

Deep navy and near-black backgrounds establish the game's tone immediately, keeping character artwork and item icons visually dominant.

02

Visual Hierarchy

Typography scales, color contrast, and layout structure guide the player's eye — from the selected character to supporting information.

03

Character Artwork as Anchor

The full-body character render on the right side grounds each screen visually, giving players immediate emotional connection to the selected character.

04

Consistent Components

Character cards, item cards, and navigation tabs all follow the same underlying system — same border treatments, padding rhythm, and type scale.

05

Clear Interaction States

Default, hover, and selected states are visually distinct across every component — players always know what is selected and what is interactive.

06

Restrained Polish

Premium details — subtle glows, metallic borders, engraved edges — are applied with discipline. Effect adds depth without visual noise.

UI System & States

Inventory System

Inventory — Selected State

The inventory screen manages a large number of items without feeling cluttered. Four key decisions define the system:

Item Card Consistency

All item cards share identical dimensions, padding, and alignment — creating a uniform grid that's easy to scan quickly.

Selected Item State

The selected item (Cursed Greatsword) is clearly distinguished with a gold accent border and highlighted name — impossible to miss, but not excessive.

Item Preview Area

The lower half of the screen showcases the selected item in a large annotated illustration, giving the player full visual context before committing to equip.

Equip / Drop Button Hierarchy

EQUIP is the primary action — gold border, stronger fill. DROP is clearly secondary — muted treatment. Players immediately know which button matters more.

Character Selection System

The character selection screen handles one of the most important decisions a player makes. The UI needed to present multiple characters clearly while making the selected state visually dominant.

Default State

Unselected character cards are muted and slightly darker — readable but visually receded, so the selected character stands out naturally.

Selected State

Jinx's card is visually dominant: gold accent border, warm gradient fill, and highlighted class title — the strongest visual treatment on the screen.

Character Preview

The full-body character render on the right side anchors the entire composition. The selected card and the artwork work together to confirm the player's choice.

Active Navigation State

The CHARACTER tab is clearly active in the top navigation — underlined and bright — while other tabs remain quiet and secondary.
